# BaiZe Agent设计文档索引

## 概述

本文档集提供了BaiZe监控平台Agent组件的完整设计文档，涵盖了架构设计、模块实现、插件机制等各个方面。

## 文档结构

### 核心架构文档
- **[Agent架构设计](agent.md)** - Agent整体架构设计，包括核心组件、生命周期管理、API设计等
- **[Metrics模块设计](metrics.md)** - 指标收集模块详细设计，重点介绍插件机制和扩展方式

### 功能模块文档
- **[Machine Info模块](machine_info.md)** - 机器信息收集模块，负责主机基础信息收集
- **[Hardware模块](hardware.md)** - 硬件信息收集模块，负责硬件详细信息收集
- **[Anomaly模块](anomaly.md)** - 异常检测模块，负责智能异常检测和预警

## 设计原则

### 1. 架构设计原则
- **模块化设计**：各功能模块独立，易于扩展和维护
- **接口驱动**：基于接口的编程，支持灵活的组件替换
- **配置驱动**：通过配置文件灵活控制功能开关
- **安全优先**：静态编译架构，避免动态代码执行风险

### 2. 文档设计原则
- **mermaid图表**：使用mermaid绘制架构图和流程图
- **结构清晰**：文档结构层次分明，便于阅读和理解
- **技术细节适度**：避免过多代码细节，重点描述架构设计
- **实用性强**：提供实际的使用指导和扩展方法

### 3. 插件设计原则
- **配置驱动**：通过配置文件控制插件启用和参数
- **工具调用**：通过调用系统命令或工具实现监控功能
- **安全隔离**：避免动态代码执行，确保系统安全
- **易于扩展**：简单的配置即可添加新的监控功能

## 快速开始

### 1. 了解整体架构
建议首先阅读[Agent架构设计](agent.md)，了解Agent的整体架构和核心概念。

### 2. 学习插件机制
阅读[Metrics模块设计](metrics.md)，了解如何通过插件扩展监控功能。

### 3. 模块功能了解
根据需要了解各个功能模块的详细设计：
- 机器信息收集：[Machine Info模块](machine_info.md)
- 硬件信息收集：[Hardware模块](hardware.md)
- 异常检测：[Anomaly模块](anomaly.md)

## 扩展指南

### 新增监控指标
1. 在配置文件中添加插件配置
2. 定义执行命令和参数
3. 配置指标名称和标签
4. 验证指标收集结果

详细步骤参考[Metrics模块设计](metrics.md)中的"如何新增插件搜集新指标"章节。

### 开发新模块
1. 实现`dataProvider`接口
2. 添加模块生命周期管理
3. 集成到Agent主结构
4. 添加HTTP API端点

### 自定义异常检测
1. 配置检测规则
2. 选择检测算法
3. 设置告警策略
4. 验证检测效果
