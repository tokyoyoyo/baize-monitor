# 数据采集方法

## 1. 采集方法总览

机器信息模块采集两类信息：

- **主机名** - `os.Hostname()`
- **IP 地址** - `net.Interfaces()`

## 2. 主机名采集

### 实现方法

调用 `os.Hostname()` 获取主机名

### 错误处理

- 成功时返回主机名
- 失败时返回 "unknown"
- 错误信息记录到 Message 字段

### 特点

- 简单：单次调用
- 快速：无延迟
- 可靠：总有返回值

## 3. IP 地址采集

### 实现方法

调用 `net.Interfaces()` 获取所有网络接口，然后遍历获取每个接口的 IP 地址

### 过滤逻辑

- 只收集启用的接口（FlagUp）
- 只收集有效 IP 地址（*net.IPNet）
- 支持 IPv4 和 IPv6

### 数据结构

返回类型：`map[string][]string`
- Key：网络接口名称
- Value：IP 地址列表

## 4. 错误处理策略

### 错误累积

- 主机名和 IP 地址错误都累积到 Message 字段
- 多个错误用分号分隔

### 部分成功

即使部分采集失败，仍返回数据：
- 主机名失败：返回 "unknown"
- IP 地址失败：返回空 map

## 5. 性能特点

### 采集耗时

- 主机名：< 1ms
- IP 地址：< 10ms
- 总计：< 15ms

### 资源占用

- 内存：可忽略
- CPU：可忽略
- 系统调用：2 次

### 采集频率建议

- 启动时：采集一次
- 按需：API 请求时采集
- 不推荐定期采集（信息不常变化）
