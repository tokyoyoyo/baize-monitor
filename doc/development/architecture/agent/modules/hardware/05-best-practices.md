# 最佳实践

## 1. 分级采集

### 优先详细信息

优先使用 dmidecode 等详细采集，失败回退到 gopsutil

### 提供回退方案

确保采集器始终能返回基础数据

## 2. 错误处理

### 静默失败

非关键错误静默处理，设置 `Success=false` 和 `Message`

### 关键错误

关键错误应返回 error

## 3. 性能优化

### 批量读取

避免重复读取相同文件

### 超时控制

设置合理的超时时间

## 4. 代码规范

### 接口实现

- 实现 `HardwareCollector` 接口
- 保持无状态设计
- 通过指针修改返回数据

### 命名规范

- 采集器命名：`<硬件>Collector`
- 文件命名：`<硬件>_collector.go`

### 测试规范

- 编写单元测试
- 覆盖成功和失败场景
- 验证数据完整性
