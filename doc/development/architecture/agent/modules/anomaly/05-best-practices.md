# 最佳实践

## 1. 命名规范

### 文件名
格式：`<type>_<detector_name>_detector.go`

### 结构体名
格式：`<type><DetectorName>Detector`（小写开头，私有类型）

### 检测项名称
格式：`<type>_<detector_name>`（小写，下划线分隔）

## 2. 错误处理

### 静默失败
非关键错误（数据获取失败）静默处理，返回空结果

### 返回错误
关键错误返回 error，由 Registry 统一处理

## 3. 性能优化

### 批量读取
避免重复读取相同文件

### 超时控制
设置合理的超时时间

### 缓存数据
利用内核缓存，避免频繁读取

## 4. 代码规范

### 接口实现
- 实现 `Detector` 接口
- 保持无状态设计
- 检测逻辑轻量级

### 自动注册
在 `init()` 中自动注册，无需手动添加

### 测试规范
- 编写单元测试
- 覆盖成功和失败场景
- 验证异常结果正确性
